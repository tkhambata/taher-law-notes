## About this page

This is a website demonstration using fictional facts. It is not legal advice and does not state the law of any jurisdiction.

The two diagrams below are attached through this page's frontmatter. No component imports are needed in the page body.

## Fictional problem question

Alex and Blair exchange messages about buying a used laptop.

- Alex sends a message discussing a price.
- Blair replies later that day.
- Some of the messages are missing from the material provided.
- Alex and Blair disagree about what their conversation meant.

No legal conclusion is supplied. The purpose is to test how notes, questions and diagrams appear together.

## Sample study notes

### Organize the facts

Create a timeline of the available messages. Separate information shown in the material from assumptions.

### Identify questions for research

- What exactly did each message say?
- Which messages are missing?
- Which jurisdiction and course materials apply?
- What authorities would need to be checked?

### Answer plan

1. Issue: state the question being considered.
2. Rule and authority: insert the verified rule and supporting source.
3. Application: explain how the available facts relate to the rule.
4. Provisional conclusion: explain the result and remaining uncertainty.
